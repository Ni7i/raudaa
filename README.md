# Rauda

Website von Rauda · روضة. Modern, schlicht und für Muslime. In Zürich gegründet.

- `index.html`: die ganze Seite (HTML, CSS und JavaScript in einer Datei)
- `assets/`: Logos, Produktbilder (`assets/p/`) und Intro-Videos (`assets/natur/`)

Live: https://rauda-site.vercel.app

Hinweis: Die Videos stammen von Pexels (kostenlose Lizenz). Die Produktfotos sind Platzhalter von Lieferanten und brauchen vor dem echten Start eigene Fotos oder die Erlaubnis der Lieferanten.
